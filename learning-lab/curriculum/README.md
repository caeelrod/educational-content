# Curriculum

Each section keeps its own folder here, matching its id in `src/sections.ts`:

- `grade-school/`: Grade 5 scope and sequence and Oklahoma standards crosswalks.
- `middle-school/`: Grades 6 to 8 lesson map, pending teacher confirmation.
- `college/`: a syllabus map placing each lesson in the undergraduate courses it supports.

A new section adds `curriculum/<section>/` with a `scope-and-sequence.md` (or syllabus map) and, if it aligns to published standards, a `standards/` folder. Do not invent alignment from example demos.
